# Spikes / Essais techniques

Throwaway experiments that check an assumption of the
[design document](../doc/en/dev/plans/design.md) before product code is written.
Each spike has a `README.md` (how to run it) and a `RESULTS.md` (what was
proven, with evidence, in French first). Spike code is never referenced by
product code. Large models are downloaded by the spike scripts, never committed.

Essais jetables qui vérifient une supposition du
[document de conception](../doc/fr/dev/plans/design.md) avant le code produit.
La synthèse des résultats est dans [doc/fr/dev/spikes.md](../doc/fr/dev/spikes.md)
([English](../doc/en/dev/spikes.md)).
