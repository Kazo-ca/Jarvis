# Décisions d'architecture (ADR)

Un ADR par décision, numéroté, écrit et fusionné avant le code qu'il décrit.
Un ADR accepté ne se modifie pas : un nouveau le remplace. Le prochain numéro
libre est indiqué dans la [mémoire du projet](../../memory/README.md).

| [0002](0002-vertical-slices-kernel-and-dependency-rules.md) | Tranches verticales, noyau partagé et règles de dépendance | Proposé |
| [0003](0003-hosts-and-native-services.md) | Hôtes (Windows WPF, Web de test, Android) et services natifs | Proposé |
| [0004](0004-configuration-storage-and-secret-vault.md) | Configuration, stockage et coffre de secrets | Proposé |
| [0005](0005-assistant-state-machine-and-orb-contract.md) | Machine à états de l'assistant et contrat de l'orbe | Proposé |
| [0006](0006-voice-chain.md) | Chaîne vocale (mot d'éveil, reconnaissance, synthèse) | Proposé |
| [0007](0007-llm-providers-and-tool-format.md) | Fournisseurs LLM et format des outils | Proposé |
| [0008](0008-languages-and-localization.md) | Langues et localisation | Proposé |
| [0009](0009-permission-and-confirmation-model.md) | Modèle de permissions et de confirmation | Proposé |

Les neuf premiers ADR sont ceux de l'étape 1, listés dans le
[document de conception](../plans/design.md#méthode-de-travail-et-premiers-adr).
Les ADR des étapes suivantes s'écrivent au début de chaque série.
